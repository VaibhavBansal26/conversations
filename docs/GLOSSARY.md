# Glossary

Domain terms as used in this repository, and how they map to the legacy ("Support") application this product was rebuilt from (see [MIGRATION-NOTES.md](MIGRATION-NOTES.md)).

| Term | Meaning | Legacy term |
| --- | --- | --- |
| **Workspace** | a customer account of the product: its members, contacts, inboxes, settings, credits and plan. Every row of data belongs to exactly one | `Account` |
| **Member / seat** | a user's membership of a workspace, with a role, a *live seat* flag (works conversations), availability and notification preferences | `Conversation` (the per-user "team seat", confusingly not a thread), `User` |
| **Role** | a named set of permissions: Owner, Manager, Agent, Viewer, or a custom role | `User.scope[]`, `is_owner` |
| **Permission** | a `resource:action` string checked by `can()`; the unit of access control ([RBAC.md](RBAC.md)) | scope strings, CASL rules |
| **Contact** | the person on the other side of a conversation (name, email, phone, tags, notes) | `crm.contacts`, `SupportConversation` |
| **Visitor** | an anonymous or identified person using the chat widget; has a *visitor session* | support user |
| **Room (conversation)** | one thread between the team and one contact across chat, SMS and email; has status `open` or `closed`, priority, assignees, snooze. The code says *room*, the UI says *conversation* | `SupportRoom` |
| **Ticket** | one issue inside a room, with a per-workspace number, status, handler, department, priority, resolution and rating; opens with the first message of an issue and ends when resolved or closed. A *conversation* (code: *room*) is the one thread per contact and outlives its tickets ([AI-AGENTS.md](AI-AGENTS.md), [ADR 0027](adr/0027-tickets-inside-rooms.md)) | `SupportRoom` status, "case" |
| **Department** | an inbox with routing configuration: hours and holidays, routing mode, capacity, service levels, overflow, members with skills and languages ([DEPARTMENTS.md](DEPARTMENTS.md), [ADR 0028](adr/0028-departments-are-inboxes.md)) | `SupportInbox` |
| **Routing mode** | how a department gives a ticket to a person: round robin, least busy, skills based or manual pick | assignment algorithm |
| **Queue** | tickets waiting for a person (`waiting_for_human` with no handler), given out oldest first as people become free | (none) |
| **Handler** | who is working a ticket: `bot:<agent id>` or `human:<member id>` | assignee (a conversation's assignee is unchanged) |
| **Team chat** | internal chat between workspace members: channels, direct and group messages, threads, reactions ([TEAM-CHAT.md](TEAM-CHAT.md)); not customer conversations | legacy generation B "conversations rooms" |
| **Team channel** | a public (anyone in the workspace can join) or private (invite-only) chat space; `#general` exists in every workspace; not to be confused with the SMS/email *channels* | |
| **Shared conversation card** | a team chat message that links to a customer conversation; its details are shown only to members who may open that conversation | |
| **Channel connection** | a workspace's own Twilio (SMS) or SendGrid (email) credentials, stored encrypted, with its own webhook URLs ([CHANNELS.md](CHANNELS.md)) | env-wide `TWILIO_*` / `SENDGRID_*` |
| **Test mode** | a channel with no real provider: messages are stored with delivery `not_sent_test_mode` and never shown as sent | the console provider |
| **Message** | one entry in a room: `kind` (text, image, voice, gif, attachment, ref, note, system), `source` (`dm` chat, `sms`, `email`), delivery state | `SupportMessage` |
| **Note** | an internal message only the team sees; never sent to the contact | `message_type: note` |
| **System message** | a line generated by the product ("Conversation reopened", "Payment received") | `message_sub_type` |
| **Card** | structured content carried in `message.meta.card` (currently the payment request) | payment-request cards |
| **Inbox** | a team queue conversations are routed to (manual or round-robin), with its own members and office hours | `SupportInbox` |
| **Embed token** | a `cvt_...` key bound to a domain that lets the widget on that site talk to the workspace | `SupportTokens` |
| **Hosted chat** | the full-page chat at `/chat`, for native web views and iframes; enabled per embed token | (new) |
| **Identity hash** | `HMAC_SHA256(secret, external_id\|email)` computed by a customer's backend so a signed-in user is recognised without a code | (new) |
| **Bridge** | the versioned JSON message protocol between a host app and the hosted chat page | (new) |
| **Widget** | the embeddable chat script `widget.js` | support widget |
| **Snooze** | hide a conversation until a time; time snoozed is excluded from resolution time | `snooze_time` |
| **Credits** | prepaid units spent by outbound SMS and email, recorded in the usage ledger | `OnebalanceQueue`, wallet |
| **Plan** | Free, Pro or Business: seat limits, monthly credits and the rate-limit tier | (none) |
| **Grace / soft lock** | the period after a failed payment during which everything works, and the state after it in which external sends and new seats are refused ([STRIPE.md](STRIPE.md)) | (none) |
| **Payment request** | a request for a customer to pay, sent inside a conversation and paid on the workspace's own Stripe account (Connect) | payment-request cards |
| **Outbox** | table written in the same transaction as a change, relayed to the event bus afterwards, so nothing is published before commit and nothing is lost on a crash | (none) |
| **Event bus** | the interface behind which Redis Streams (default) or Kafka/NATS deliver outbox events to consumer groups | (none) |
| **Audience** | the set of sockets that should receive an event, computed from visibility rules instead of from per-room channels | socket rooms |
| **Resync** | a client refetching state over REST after `server:resync` or a reconnect | (none) |
| **Policy (rate limit)** | a named limit (algorithm, key, numbers, failure mode); routes and socket events declare which they pass through ([RATE-LIMITING.md](RATE-LIMITING.md)) | (none) |
| **Tier** | `free`, `pro` or `business`: scales the plan-dependent policies; can be overridden by an operator | (none) |
| **Platform admin / operator** | a person who runs the installation, outside any workspace ([ADMIN.md](ADMIN.md)) | agency/white-label hierarchy |
| **Support access** | a 15-minute read-only token an operator uses to look at a workspace; recorded in that workspace's audit log | (none) |
| **Pepper** | per-workspace secret used to derive pseudonymous `contact_key`s for analytics exports ([ANALYTICS.md](ANALYTICS.md)) | (none) |
| **CSAT** | customer satisfaction score (1 to 5) given by the visitor after a conversation is closed | (none) |
| **Hot room** | a single room receiving a very high write rate, which serialises on its sequence counter ([PERFORMANCE.md](PERFORMANCE.md)) | (none) |
| **Seq** | the per-room, contiguous message sequence number used for ordering and gap detection | `hr_time` |
